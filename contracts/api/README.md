# Contratos API

Esta carpeta alojara contratos HTTP por microservicio, idealmente en OpenAPI.

## Regla

Cada endpoint debe declarar:

- metodo y ruta;
- permisos requeridos;
- request;
- response;
- errores esperados;
- eventos publicados, si aplica.

## Servicios

- `production-service`
- `inventory-service`
- `purchasing-service`
- `sales-service`
- `expenses-service`
- `costing-service`
- `reporting-service`
- `admin-service`
- `accounting-service`
