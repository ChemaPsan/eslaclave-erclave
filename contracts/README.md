# Contratos ERClave

Los contratos son el punto de seguridad entre microfrontends y microservicios.

## Tipos de contrato

- API HTTP por servicio.
- Eventos entre servicios.
- Contrato de montaje de microfrontends.
- Permisos por accion.
- Estados validos por entidad.

## Regla

Si un cambio rompe un contrato, debe versionarse y documentarse antes de modificar frontend o backend.
